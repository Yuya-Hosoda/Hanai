# 関連研究ドラフト v1 — 監査レポート

## 1. 監査結果の概要

ドラフト v1 は研究方向を概ね反映しているが、いくつかの主張は強すぎる。特に、MoshiRAG を確立済み研究のように扱う表現、臨床的有効性を連想させる表現、ジェスチャ安全標準が存在するかのような表現は修正が必要である。

---

## 2. 重要な修正点

| 重要度 | 問題 | 修正方針 |
|---|---|---|
| Critical | MoshiRAG の査読状況が未確定。 | 「参考アーキテクチャ」「プレプリント」と明記する。 |
| Critical | 臨床効果を示唆する表現が混ざる可能性。 | ユーザ知覚と工学評価に限定する。 |
| High | ジェスチャ安全標準があるように読める。 | 標準は未確認であり、設計制約として提示する。 |
| High | M4 の文献基盤が不足。 | U5・U6 調査中と明記する。 |
| Medium | 統合ギャップの表現が広すぎる。 | 調査範囲に基づく限定的主張にする。 |

---

## 3. 優先修正順

1. MoshiRAG の扱いを弱める。
2. 臨床効果に見える表現を削除する。
3. 安全制約を「標準」ではなく「設計要求」と呼ぶ。
4. M4 の未確定性を明記する。
5. 統合ギャップを文献調査範囲に限定して書く。
