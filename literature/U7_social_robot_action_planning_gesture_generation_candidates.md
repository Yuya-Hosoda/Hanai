# U7 候補文献リスト
## 社会的ロボットの行動計画とジェスチャ生成

**状態:** 候補文献リスト。
**研究上の問い:** 音声対話ロボットが、会話状況に応じて安全で意味のあるジェスチャを選ぶには、どのような行動計画方式が適切か。
**作成日:** 2026-05-16

---

## 1. 調査範囲

Behavior Tree、finite state machine、robot action planning、social robot gesture generation、LLM robot behavior planning、BEAT gesture、care robot、human-robot interaction などを検索した。社会的ロボット、行動計画、ジェスチャ分類、LLM とロボット制御の接続を中心に調べた。

---

## 2. 候補文献の概要

本研究では、ジェスチャを自由生成するのではなく、事前に定義した安全なコマンド集合から選ぶ方式を採る。そのため、Behavior Tree（BT）の形式的な構造、BT と FSM の比較、社会的ロボットでの BT 利用、BEAT などのジェスチャ分類、LLM によるロボット行動生成の研究を組み合わせて位置づける。

| 区分 | 使い方 |
|---|---|
| Behavior Tree の基礎 | モジュール性、再利用性、条件分岐の管理しやすさを説明する。 |
| BT と FSM の比較 | 複雑な行動を扱う場合に BT が拡張しやすいという根拠として使う。 |
| 社会的ロボット応用 | BT が実ロボットの行動制御に使われていることを示す。 |
| ジェスチャ分類 | beat、deictic、iconic、metaphoric などの語彙設計に使う。 |
| LLM とロボット行動 | LLM 出力をそのまま動作にせず、安全なコマンド層を挟む必要性を説明する。 |

---

## 3. 採用判断

### 採用（6 件）
BT の基礎文献、BT の比較・安全分析、社会的ロボット応用、BEAT のジェスチャ分類、LLM ベースのロボット行動生成関連文献を採用する。

### 保留（4 件）
LLM による自由な動作生成や感情表出の研究は参考になるが、本研究の安全制約付きコマンド計画とは距離があるため、補助的に扱う。

### 除外または再分類（2 件）
音声同期やユーザ評価が中心の文献は U8 または U9 に回す。

---

## 4. マテリアルギャップ

メンタルヘルス支援文脈で、全二重音声対話、RAG、BT による事前定義ジェスチャ計画、ジェスチャ安全制約を一つのロボットシステムとして統合した査読済み研究は見つかっていない。この不足が U7 の主要ギャップである。

---

採用文献から、BT の構造、ロボット制御への適用例、ジェスチャ分類、自由生成ではなく登録コマンドを使う安全設計の根拠を抽出する。
